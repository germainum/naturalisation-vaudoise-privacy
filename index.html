Politique de confidentialité

Naturalisation vaudoise — application parodique, sans aucune valeur légale, cantonale ou fédérale.

Ce que l'application ne fait pas

  • Pas de compte utilisateur, pas d'e-mail, pas de numéro de téléphone.
  • Pas de suivi publicitaire, pas de SDK tiers d'analyse ou de publicité.
  • Pas de collecte de nom d'état civil ni de localisation.

Ce que l'application stocke — localement, sur l'appareil

Via le stockage de préférences de l'appareil :

  • le surnom saisi pour le registre cantonal (un pseudonyme choisi librement).

Ce que l'application stocke — sur le serveur

Uniquement si vous choisissez de vous inscrire au registre cantonal des candidatures :

  • le surnom saisi (24 caractères maximum) ;
  • le taux de vaudoisité obtenu et le nombre de points ;
  • la date d'inscription.

Ce registre est public : le surnom et le score de chaque candidature apparaissent dans le classement, trié par score, visible par toute personne utilisant l'application.

Aucune de ces données ne permet, à elle seule, d'identifier une personne réelle. Les entrées du registre sont définitives : il n'existe pas de fonction de modification ou de suppression depuis l'application. Pour toute demande de suppression, contactez l'éditeur via le contact ci-dessous.

Partage vers WhatsApp

L'application propose un bouton pour défier des proches sur WhatsApp. Il ouvre WhatsApp avec un message pré-rempli (le taux de vaudoisité obtenu et le nom de l'application) : c'est l'utilisateur qui choisit ensuite, dans WhatsApp, à qui l'envoyer. Aucune donnée n'est transmise automatiquement sans cette action explicite.

Réseau

Le test se joue entièrement hors connexion. Seule l'inscription au registre cantonal (optionnelle) nécessite une connexion réseau.

Contact
